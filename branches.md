# Branches and Merging

# Branch

A branch is a separate line of development in a Git repository. It
allows changes to be made without immediately changing the main
branch.

# Merge

A merge combines changes from one branch into another branch.

# Why Use Branches?

Branches allow developers to work on features or changes separately
before combining them with the main project.

# Example

A developer can create a branch for a new feature, make commits on
that branch, and then merge the branch into `main` when the work is
finished.
