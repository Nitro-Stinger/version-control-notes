# Command Line Notes

# What is the Command Line?

The command line is a text-based way to interact with a computer.

# Common Commands

`pwd` - Shows the current directory.

`ls` - Lists files and folders.

`cd` - Changes directories.

`mkdir` - Creates a directory.

`touch` - Creates a file.

`rm` - Removes a file.

`git status` - Shows the current Git status.

# Git and the Command Line

Git commands can be run through the command line to create commits,
switch branches, and interact with remote repositories.
