# Git Basics

# What is Git?

Git is a version control system used to track changes to files and
projects.

# Repository

A repository is a location where Git tracks a project's files and
history.

# Commit

A commit is a saved snapshot of changes in a Git repository.

# Staging

The staging area allows you to select changes that will be included
in the next commit.

# Push

Push sends local commits to a remote repository such as GitHub.

# Pull

Pull retrieves changes from a remote repository and incorporates them
into the local repository.
